# 跨领域组合编排模板（cross-domain combo）

> **用途**：任务命中**两个及以上**领域标签（`biomed` / `ai` / `general`）时，主理人在
> Route 步骤直接套用本模板填空，产出可执行的 fan-out + 串行依赖链 + 仲裁方案。
> 依据：`references/agent-registry.md` §交叉领域组合路由模板（SSOT）；本文件是可填的执行单，
> 与 registry 冲突时以 registry 为准。
> **判定前置**：领域标签集合必须由任务文本或用户确认得出；缺标签 → 走 CLARIFY 阶段，
> 不猜、不进 EXECUTE。

> **不要留空**——留空会掩盖「漏想」与「确认不需要」的区别。

## 5. 证据要求（两侧口径不同，不得互相顶替）

| 侧 | 证据标识（每条 evidence 必带） | 等级口径 | 硬约束 |
|----|--------------------------|---------|--------|
| **biomed 侧** | `{{PMID / DOI / 数据库 accession}}` | `{{GRADE 1a-1b-2a-2b-3a-3b-4-5}}` | 不得用「模型预测值」替代实验/文献证据；反之亦然 |
| **ai 侧** | `{{模型名+版本号 / 基准数据集名 / 论文 arXiv ID}}` | `{{基准可比性口径}}` | 必须写清版本与基准名，无版本号的模型结论视为不可复现证据 |
| **general 侧** | `{{meta 分析来源 / 评估量规 / 抽样与统计方法出处}}` | `{{GRADE 或等价量表}}` | 样本量与量规定义须先于结论给出 |

**复评要求**：`methodological-reviewer` 对**两侧分别**复评——
biomed 侧按 GRADE，ai 侧按基准可比性与可复现性，general 侧按方法学合规；
**不得**用一个统一口径把两侧压平。

**禁止编造**：未检索到就写「未检索到」，并区分「关键词问题」与「真空白」；
禁止虚构 PMID / DOI / arXiv ID / URL / 数值 / 结论。
